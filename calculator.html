Reverse Polish Notation Calculator Instruction

Introduction

Reverse Polish Notation (RPN) is a method for representing mathematical expresions in which the operator symbol is placed after the operands being operated on. Strong side of this method is the fact, that it eliminates the need to use parentheses. User is responsible for correctly typing in calculation. Using this type of calculator is simple, but requires some understanding and practice. This instruction aims to explain how to use Reverse Polish Notation Calculator. For more information go to this website.

The idea

While using this calculator, you won't be using parentesies. Instead, Reverse Polish Notation introduces spaces as number separator. You should put space after every seprate number. Putting space after operand is not nessecery but not wrong. The main idea of RPN is that operation is always between two numbers and this calculator assumes that. Next important thing is operand placement. Operand goes always after numbers, on which operation is performed. Please see examples below to visualize calculator usage.

Examples

Simple addition of two numbers:

5 + 5 + 3

→

5 5 3 ++

The rest of the operation adequately.

Priority of operations:

10 - 5 * 2

→

10 5 2 *-

Using parenthesies:

100 - (25 + 5) / 6

→

100 25 5 + 6 /-

Summary

  • There are no parenthesies, instead RPN introduces spaces as separators,
  • Operations are performed between two numbers (except percent sign),
  • Operand always goes after numbers on which operation is performed.
